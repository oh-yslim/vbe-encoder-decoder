VBE Codec

Encode and decode Microsoft Script Encoder .vbs and .vbe files.

✓ No file uploads to servers   ✓ No backend   ✓ No script execution

1. Source

File input preserves original bytes. Pasted text is encoded using the selected character set. Automatic legacy encoding detection is not reliable.

WSH-safe encode converts non-ASCII characters inside VBScript quoted string literals into ChrW(&HXXXX) expressions before encoding. Non-ASCII outside quoted strings is rejected to avoid silent changes. This does not validate all VBScript syntax.

2. Result

Scripts are never executed

Choose Encode or Decode.

VBE is obfuscation, not encryption. Never execute scripts from untrusted sources.

Raw UTF-8 Unicode roundtrips do not prove Windows Script Host compatibility. Legacy code pages cannot represent every Unicode character. WSH-safe encoding generates ASCII-only source, including ChrW expressions for Unicode string literals. Console fonts and output code pages may still affect display.
