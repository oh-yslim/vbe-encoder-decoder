1. 변환할 내용

파일 선택 시 원본 바이트를 직접 변환합니다. 붙여넣기는 선택한 문자 인코딩으로 변환합니다.

2. 변환 결과

원문은 실행되지 않습니다

Encode 또는 Decode를 선택하세요.

VBE는 암호화가 아닌 난독화입니다. 신뢰하지 않는 스크립트를 실행하지 마세요.

VBE는 레거시 바이트 지향 형식입니다. UTF-8/이모지 왕복 테스트가 성공하더라도 Windows Script Host에서 실제 실행 가능하다는 뜻은 아닙니다. 한국 Windows 실행용은 CP949 등 원래 코드페이지를 선택하세요.
