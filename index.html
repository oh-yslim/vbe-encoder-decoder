VBE Codec

Encode and decode Microsoft Script Encoder .vbs and .vbe files.

✓ Files stay in your browser   ✓ No manual output encoding   ✓ Windows compatibility tested separately

1. Input

Files are read using BOM/Unicode checks and guarded legacy-code-page detection. Ambiguous inputs are rejected rather than silently misdecoded. Download encoding is chosen from the current text, not the original file format.

Download encoding: ASCII (when the input is ASCII-only), otherwise UTF-16 LE with BOM.

2. Result

Text is never executed

Result download encoding: —

Choose Encode or Decode.

VBE is obfuscation, not encryption. Never execute scripts from untrusted sources.

Downloads: ASCII when all characters are U+0000–U+007F; UTF-16 LE with BOM otherwise, including Unicode in comments. Invalid source controls and unpaired surrogates are rejected.

Diagnostic decoding can display unverified text even if length, checksum, or recovered-control checks fail. Unverified downloads require explicit acknowledgement. Validation does not execute VBScript or guarantee Windows Script Host compatibility. BOM-less legacy files may have an undetectable or ambiguous code page.
